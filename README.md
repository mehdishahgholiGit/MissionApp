# MissionApp

اپلیکیشن اندروید مدیریت هزینه مأموریت، جایگزین فرم Excel.

## قابلیت‌ها
- ثبت و ویرایش مأموریت
- ثبت هزینه‌های تهران، بین‌شهری، درون‌شهری و متفرقه
- محاسبه حق مأموریت، تعطیلات، بلیط، هتل و جمع کل
- ثبت علی‌الحساب و تسویه
- تولید برگه خلاصه مأموریت و روکش سند حسابداری به صورت PDF
- ذخیره اطلاعات روی خود گوشی
- پشتیبان‌گیری خودکار در پوشه‌ای که کاربر انتخاب می‌کند (با حذف برنامه از بین نمی‌رود) و بازیابی بعد از نصب دوباره

ساخت APK با GitHub Actions انجام می‌شود؛ فایل APK به عنوان artifact خروجی workflow منتشر می‌شود.
